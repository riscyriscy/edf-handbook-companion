# Templates for a product team

The templates of Appendix D of The Embedded AMD EDF Handbook, one Markdown file each. They are designs, not AMD material, and none was tested on a product. Copy a file into the project wiki or repository, fill the empty column, and keep it under version control with the layers. A blank cell is a decision that nobody has made.
